# AUREN

AUREN is a modern fashion and lifestyle ecommerce storefront built around the idea of **The New Everyday**.

The store features a curated selection of shoes, bags, watches, and accessories, with a Nigeria-focused shopping experience and direct WhatsApp ordering.

## Live Demo

https://auren-store-delta.vercel.app/

## Features

- Responsive ecommerce storefront
- Product catalogue with 22 products
- Product search
- Category filtering
- Dynamic product detail pages
- Related product recommendations
- Direct WhatsApp ordering
- Nationwide delivery messaging
- Cloudinary-hosted product imagery
- SEO metadata
- Open Graph and social sharing metadata
- Dynamic sitemap
- Robots.txt
- Responsive navigation
- Accessible interactive elements
- Custom favicon

## Categories

- Shoes
- Bags
- Watches
- Accessories
