# Contributing to AUREN

Thanks for your interest in contributing to AUREN.

AUREN is a storefront project built with Next.js, TypeScript, and Tailwind CSS.

## Before Contributing

Please check the existing issues and pull requests before starting work to avoid duplicate efforts.

For larger changes, open an issue first so the proposed change can be discussed before implementation.

## Making Changes

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes while keeping the existing design and code structure consistent.
4. Test the project locally.
5. Commit your changes with a clear commit message.
6. Open a pull request with a clear description of what changed and why.

## Code Guidelines

- Use TypeScript for application code.
- Keep components focused and reusable.
- Follow the existing project structure.
- Maintain responsive and accessible interfaces.
- Avoid unnecessary dependencies.
- Keep changes focused on the purpose of the pull request.

## Pull Requests

Pull requests should:

- Clearly explain the changes made.
- Include relevant screenshots for significant UI changes.
- Avoid unrelated changes.
- Pass the project's build before submission.

## Questions

For questions about the project, open an issue with enough context for the problem or suggestion to be understood.
