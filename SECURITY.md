# Security Policy

## Supported Versions

Security updates are provided for the latest version of the project.

## Reporting a Vulnerability

If you discover a security vulnerability in AUREN, please do not publicly disclose it through a GitHub issue.

Instead, report it privately to:

**Email:** tgghub01@gmail.com

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant screenshots or technical details

We will review reported vulnerabilities and take appropriate action.

## Scope

This policy applies to the AUREN repository and its publicly available application code.

Please do not submit security reports for third-party services or infrastructure that AUREN depends on, such as Vercel or Cloudinary. Those should be reported to the respective provider.
